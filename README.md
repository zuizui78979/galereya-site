# Галерея — upgraded landing

Статический продающий сайт для паба «Галерея», Волгоград, ул. Мира, 11.

## Что сделано
- продающий первый экран и сильный CTA «Забронировать стол»;
- акцент на футбол, 10 экранов, атмосферу, пиво и историю с 1997 года;
- фото-блок, отзывы, цены, контакты и маршрут;
- форма бронирования с готовым сообщением в WhatsApp;
- адаптивная мобильная версия;
- базовая SEO-структура.

## Публикация
Откройте `index.html` или разместите папку на статическом хостинге.
Перед публикацией проверьте актуальность фотографий, меню и подключите реальную систему бронирования, если она есть.
